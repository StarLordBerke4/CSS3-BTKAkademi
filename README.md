### 🧙‍♂️ BTK Akademi | CSS ile Web Tasarımı Eğitimi
<p>BTK Akademi’nin "CSS ile Web Tasarımı Eğitimi", katılımcılara modern web tasarımının görsel temellerini öğretmeyi amaçlayan kapsamlı ve uygulamalı bir programdır. Bu eğitim, hem web geliştirme alanına yeni başlayanlar hem de HTML bilgilerini görsel tasarımla destekleyerek profesyonel bir düzeye çıkarmak isteyen bireyler için özel olarak hazırlanmıştır. Eğitim süreci boyunca katılımcılar, CSS (Cascading Style Sheets) kullanarak etkileyici, kullanıcı dostu ve responsive (duyarlı) web arayüzleri geliştirmeyi öğrenirler.</p>
<p>Katılımcılar, HTML ile yapılandırılan içerikleri estetik ve işlevsel hale getirmek için CSS'in sunduğu olanakları öğrenirken; yazılım geliştirme, arayüz tasarımı ve kullanıcı deneyimi gibi alanlarda da temel bilgi ve beceriler edinirler. Eğitim sonunda, kendi web projelerinde profesyonel düzeyde stil düzenlemeleri yapabilecek düzeye gelmeleri hedeflenmektedir.</p>

### 📋 Eğitim Programı Genel Olarak Şu Başlıkları Kapsamaktadır:
- <b>CSS Temelleri</b> Katılımcılar, CSS’in temel sözdizimi, seçiciler (selectors), özellikler (properties) ve değerler (values) gibi yapıları öğrenirler. Harici, dahili ve satıriçi CSS tanımlamaları arasındaki farklar detaylı bir şekilde ele alınır.
- <b>Kutu Modeli (Box Model)</b> CSS’in temel yapı taşlarından biri olan kutu modeli, elementlerin genişlik, yükseklik, dolgu (padding), kenar boşluğu (margin) ve kenarlık (border) ilişkileriyle birlikte ayrıntılı olarak işlenir. Bu modül, düzenin görsel kontrolünü sağlamada kritik öneme sahiptir.
- <b>Renkler, Yazı Tipleri ve Metin Biçimlendirme</b> Bu bölümde renk tanımlamaları (hex, rgb, hsl), yazı tipi seçimi, yazı tipi boyutlandırmaları, satır yüksekliği gibi tipografik düzenlemeler ele alınır. Tasarıma estetik katmak adına temel renk teorisi ve uyumlu renk kullanımı da açıklanır.
- <b>Pozisyonlandırma ve Yerleşim</b> Elementlerin sayfa üzerindeki konumlandırmaları; static, relative, absolute, fixed ve sticky gibi pozisyon değerleriyle anlatılır. Float ve clear gibi eski tekniklere ek olarak Flexbox ve Grid sistemleriyle modern yerleşim teknikleri uygulanır.
- <b>Responsive Web Tasarımı (Mobil Uyumlu Tasarım)</b> Farklı ekran boyutlarına göre uyumlu tasarımlar oluşturmak amacıyla media query kullanımı öğretilir. Katılımcılar, mobil cihazlar, tabletler ve masaüstü ekranlar için ayrı ayrı tasarım yapabilme becerisi kazanırlar.
- <b>Animasyonlar ve Geçiş Efektleri</b> CSS ile geçiş (transition), dönüşüm (transform) ve animasyon (keyframes) teknikleri öğrenilerek kullanıcı etkileşimini artıran dinamik tasarım unsurlarına yer verilir.
- <b>Uygulamalı Proje Geliştirme</b> Eğitimin sonunda katılımcılar öğrendikleri tüm CSS becerilerini kullanarak küçük ölçekli projeler geliştirirler. Bu projeler portföylerinde yer alacak nitelikte olup, gerçek dünya problemlerine çözüm sunacak şekilde yapılandırılır.

### 🎨 CSS Nedir?
<p>CSS (Cascading Style Sheets), HTML ile oluşturulan web içeriklerinin görsel olarak biçimlendirilmesini sağlayan stil tanımlama dilidir. Tim Berners-Lee'nin geliştirdiği HTML'in sınırlı görsel düzenleme olanaklarına çözüm olarak geliştirilen CSS, içerik ile sunumu birbirinden ayırır. Bu sayede web sayfalarının estetik, okunabilir ve kullanıcı dostu olması sağlanır.</p>

<a href=""><img align="center" src="https://github.com/StarLordBerke4/CSS3-BTKAkademi/blob/main/G%C3%B6rseller/sta-je-css.png" alt="html" width="1100"/></a>

<p>CSS, bir web sitesinin renklerinden yazı tipine, düzeninden geçiş animasyonlarına kadar pek çok tasarım unsurunu kontrol etme imkânı tanır. Web tasarımının temel yapı taşı olan bu dil, geliştiricilere ve tasarımcılara sade ve sürdürülebilir kod yapılarıyla profesyonel arayüzler oluşturma esnekliği sunar. </p>
